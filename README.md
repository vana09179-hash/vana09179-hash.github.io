# ТЮЛЕНЬ ДРОП

Мемный сайт открытия кейсов с тюленями и рыбками. Живёт на GitHub Pages: https://vana09179-hash.github.io (публикуется автоматически при пуше в `main`, через 1–2 минуты).

> Файл написан для людей и для ИИ-помощников (Claude Code, Cursor, Copilot): прочитай его целиком, прежде чем менять код.

## Главное правило
**Главный герой — Мега-Тюлень** (`img/mega.webp`: тюлень в короне с золотой рыбкой). Не заменять, не удалять; в видео, баннерах и промо он всегда в центре.

## Как устроено
- **`index.html`** — весь сайт в одном файле: CSS в `<style>`, разметка, потом один большой IIFE-скрипт. Библиотек и сборки нет, просто открывается в браузере.
- **`img/`** — все картинки (`*.webp`). Имя файла = ключ предмета (`diamond.webp` → `I.diamond`).
- **`admin.html`** — админка (закрыта паролем). Статистика, карта аккаунтов, журнал заходов, бан и выдача предметов.
- **`privacy.html`** — политика конфиденциальности (сайт записывает IP, страну и действия игроков — это написано в политике; при добавлении нового сбора данных обновляй её).
- `robots.txt`, `sitemap.xml`, `site.webmanifest`, иконки, `og-image.jpg` — SEO и значок сайта.

## Устройство игры (`index.html`)
- `RAR` — редкости: Ширпотреб → Промышленное → Засекреченное → Тайное → **Разноцветное** (внутренний ключ `gold`, это самая редкая).
- `I = {...}` — все предметы: `ключ:{n:'Название', r:'редкость', v:ценность}`. Самые дорогие: Алмазный тюлень (15000, №1) и Мега-Тюлень (10000, №2).
- `CASES = [C('id','img','Название','описание',цена,'#цвет',[категории],[предметы],'тег')]` — кейсы. Сразу после массива блок «экономика кейсов» **пересчитывает цены по реальному дропу** (`luck` + ожидаемая ценность). Бесплатные кейсы (исходная цена ≤ 50) получают только Ширпотреб/Промышленное/Засекреченное.
- `caseOdds(cs)` — шансы выпадения; `pickWeighted(cs)` — выбор приза.
- Режимы: Кейсы, Апгрейдер, Контракты, Битва кейсов, Колесо бонуса (раз в день), Продажа. У каждого свой `<section class="view" id="view-...">` и функция `show(mode)`.
- Экономика (блок «ЭКОНОМИКА: ракушки»): баланс в `localStorage['td_bal']`, старт 1000; продажа предмета за `v * 0.5`; контракт стоит 10% от максимума; битва = `(цена кейса × раунды) / боты`.
- Данные игрока (улов, уровень, баланс) лежат в `localStorage` браузера. Это игра без сервера, поэтому «взломать» баланс может любой, кто откроет консоль.

## Серверная часть (Google Apps Script, у владельца)
Адрес скрипта прописан в `index.html` и `admin.html` (`ACC_URL`, `LOG`). Скрипт ведёт приватную Google-таблицу: журнал заходов, игроки (бан, подарки), защита колеса от повторов. Исходник скрипта и пароль админки **не хранятся в репозитории**: за ними обращайся к владельцу. Без пароля админка и база недоступны, а сайт работает.

## Как проверять изменения
1. Запусти локальный сервер в папке проекта: `python -m http.server 8765`.
2. Открой http://localhost:8765, проверь консоль браузера (ошибок быть не должно).
3. Проверь на телефоне (ширина 375px): ничего не вылезает за экран.
4. Только потом `git push`.

## Правила
- Все видимые тексты — по-русски, без эмодзи в интерфейсе (используй 3D-картинки из `img/`).
- Не вставлять в HTML пользовательский текст без `esc(...)` (защита от XSS).
- Не коммитить пароли, ключи и IP игроков.
- Для больших правок лучше работать в отдельной ветке и присылать Pull Request.
