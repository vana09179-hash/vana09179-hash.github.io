# Инструкции для ИИ-помощников (Codex, Cursor, Copilot и др.)

Сначала прочитай README.md целиком.

Главное:
- Сайт — один файл index.html, картинки в img/, админка в admin.html.
- Мега-Тюленя (img/mega.webp) не менять и не удалять: он главный герой.
- Весь текст по-русски, без эмодзи в интерфейсе.
- Ники и пользовательский текст вставлять только через esc() (защита от XSS).
- Проверять локально (python -m http.server 8765), в консоли браузера не должно быть ошибок, на ширине 375px ничего не вылезает за экран.
- Пароли, ключи и IP игроков не коммитить.
- Большие правки делать в отдельной ветке и присылать Pull Request.
